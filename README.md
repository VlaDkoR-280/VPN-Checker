# VPN-Checker

## Описание
Скрипты настраивают изолировнные маршруты для работы с внешним VPN
Запуск скриптов осуществляется с sudo
---
После запуска setup скрипты настроят VPN, а также подготовится билд программы. При запуске скриптов все параметры вшиваются в испольняемый файл.
Запуск программы осуществялется через sudo (так как внутри запускается тест соединения через настроенный namespace).


_в случае ошибок в скриптах можно запустить скрипт:_
```bash
sudo make clear
```
_(если указывали доп агументы, укажите их также и здесь)_
## Старт

```bash
sudo make setup bot-token="YOUR-BOT-TOKEN" vpn-conf=/path/to/vpn.conf 
```

### Список аргументов:
| Аргумент | Описание                                   | Базовое значение  |
|----------|--------------------------------------------|-------------------|
|bot-token| токен бота для telegram API                | -                 |
|prefix| префикс для именования ns, bridge, if и тд |vpn-test|
|base-bot-name| навазвание бота                            |VPN Status|
|GO| путь к комипилятору go                     |/usr/local/go/bin/go|
|build-path| полный путь для билда                      |./build|

---

## Запуск программы
```bash
sudo ./build
```
_или другой путь к файлу_

# Настройка crontab
1. Добавить запуск компанды без пароля
```bash
sudo visudo
# в конце файла
username ALL=(ALL) NOPASSWD: /full/path/to/build
```
2. Настроить crontab
```bash
sudo crontab -e
# в файле
*/20 * * * * sudo /tmp/vpn-checker-program >> /tmp/vpn-bot-debug.log 2>&1
```
